# dataset

## CICIDS2017

official source: https://www.unb.ca/cic/datasets/ids-2017.html

the official page describes CICIDS2017 as a labelled network-flow dataset containing benign and common attack traffic, with more than 80 network-flow features generated using CICFlowMeter. the collection covers five days from monday through friday.

for a smaller/easier-to-download copy, a kaggle mirror is available:
https://www.kaggle.com/datasets/dhoogla/cicids2017

recommended github practice: keep the dataset link and metadata in the repository, but do not upload an 800+ mb raw csv if the repository has size limits. upload a permitted sample/processed subset and provide the official download link when necessary.
